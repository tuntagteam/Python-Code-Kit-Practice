# แบบฝึกหัด Python 

---

## ข้อ 1: แนะนำตัว

รับชื่อเล่นและอายุของผู้ใช้ แล้วแสดงข้อความแนะนำตัวตามรูปแบบที่กำหนด

### Input

- บรรทัดที่ 1: ชื่อเล่น 1 คำ
- บรรทัดที่ 2: อายุ เป็นจำนวนเต็ม

### Output

แสดงข้อความ `My name is NAME and I am AGE years old.` โดยแทน `NAME` และ `AGE` ด้วยข้อมูลที่รับมา

### ตัวอย่าง

**Input**

```text
Mali
15
```

**Output**

```text
My name is Mali and I am 15 years old.
```

## ข้อ 2: พื้นที่สี่เหลี่ยมผืนผ้า

รับความกว้างและความยาวของสี่เหลี่ยมผืนผ้า แล้วคำนวณพื้นที่

### Input

- บรรทัดที่ 1: ความกว้าง เป็นจำนวนเต็มบวก
- บรรทัดที่ 2: ความยาว เป็นจำนวนเต็มบวก

### Output

แสดงพื้นที่ของสี่เหลี่ยมผืนผ้าเป็นจำนวนเต็ม

### ตัวอย่าง

**Input**

```text
5
8
```

**Output**

```text
40
```

## ข้อ 3: แปลงเวลา

รับจำนวนวินาทีทั้งหมด แล้วแปลงเป็นจำนวนนาทีและวินาทีที่เหลือ

### Input

- จำนวนวินาทีทั้งหมด เป็นจำนวนเต็มที่มากกว่าหรือเท่ากับ 0

### Output

แสดงผลในรูปแบบ `M minute(s) S second(s)`

### ตัวอย่าง

**Input**

```text
135
```

**Output**

```text
2 minute(s) 15 second(s)
```

## ข้อ 4: เลขคู่หรือเลขคี่

รับจำนวนเต็ม 1 จำนวน แล้วตรวจสอบว่าเป็นเลขคู่หรือเลขคี่

### Input

- จำนวนเต็ม 1 จำนวน

### Output

- แสดง `Even` ถ้าเป็นเลขคู่
- แสดง `Odd` ถ้าเป็นเลขคี่

### ตัวอย่างที่ 1

**Input**

```text
24
```

**Output**

```text
Even
```

### ตัวอย่างที่ 2

**Input**

```text
17
```

**Output**

```text
Odd
```

## ข้อ 5: ตัดเกรด

รับคะแนนสอบ แล้วแสดงเกรดตามเกณฑ์ต่อไปนี้

| คะแนน | เกรด |
|---:|:---:|
| 80–100 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| 0–49 | F |

### Input

- คะแนนสอบ เป็นจำนวนเต็มตั้งแต่ 0 ถึง 100

### Output

แสดงเกรดเพียง 1 ตัวอักษร

### ตัวอย่าง

**Input**

```text
76
```

**Output**

```text
B
```

## ข้อ 6: ค่ามากที่สุดในสามจำนวน

รับจำนวนเต็ม 3 จำนวน แล้วแสดงจำนวนที่มีค่ามากที่สุด โดยจำนวนที่รับมาอาจมีค่าเท่ากันได้

### Input

- จำนวนเต็ม 3 จำนวน อยู่ในบรรทัดเดียวกันและคั่นด้วยช่องว่าง

### Output

แสดงจำนวนที่มีค่ามากที่สุด

### ตัวอย่าง

**Input**

```text
12 35 27
```

**Output**

```text
35
```

## ข้อ 7: นับเลขจาก 1 ถึง N

รับจำนวนเต็มบวก `N` แล้วใช้ `while loop` แสดงตัวเลขตั้งแต่ 1 ถึง `N` บรรทัดละ 1 จำนวน

### Input

- จำนวนเต็ม `N` โดย `N >= 1`

### Output

แสดงตัวเลขตั้งแต่ 1 ถึง `N` บรรทัดละ 1 จำนวน

### ตัวอย่าง

**Input**

```text
5
```

**Output**

```text
1
2
3
4
5
```

---

## ข้อ 8: ผลรวมตั้งแต่ 1 ถึง N

รับจำนวนเต็มบวก `N` แล้วใช้ `while loop` หาผลรวมของจำนวนเต็มตั้งแต่ 1 ถึง `N`

ตัวอย่างเช่น เมื่อ `N = 5` ผลรวมคือ `1 + 2 + 3 + 4 + 5 = 15`

### Input

- จำนวนเต็ม `N` โดย `N >= 1`

### Output

แสดงผลรวมเป็นจำนวนเต็ม

### ตัวอย่าง

**Input**

```text
5
```

**Output**

```text
15
```

---

## ข้อ 9: แม่สูตรคูณ

รับจำนวนเต็ม `N` แล้วใช้ `while loop` แสดงแม่สูตรคูณของ `N` ตั้งแต่คูณ 1 ถึงคูณ 12

### Input

- จำนวนเต็ม `N` 1 จำนวน

### Output

แสดงสูตรคูณ 12 บรรทัด ในรูปแบบ `N x I = RESULT`

### ตัวอย่าง

**Input**

```text
3
```

**Output**

```text
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
3 x 11 = 33
3 x 12 = 36
```

---

## ข้อ 10: ผลรวมของตัวเลขแต่ละหลัก

รับจำนวนเต็มบวก `N` แล้วใช้ `while loop` หาผลรวมของเลขโดดทุกหลักของ `N`

ตัวอย่างเช่น `4725` มีผลรวมของเลขโดดเท่ากับ `4 + 7 + 2 + 5 = 18`

> คำใบ้: ใช้ `% 10` เพื่อหาเลขหลักสุดท้าย และใช้ `// 10` เพื่อตัดเลขหลักสุดท้ายออก

### Input

- จำนวนเต็มบวก `N`

### Output

แสดงผลรวมของเลขโดดทุกหลักเป็นจำนวนเต็ม

### ตัวอย่าง

**Input**

```text
4725
```

**Output**

```text
18
```

---

## หัวข้อที่ได้ฝึก

1. `input()` และ `print()`
2. ตัวแปรและชนิดข้อมูล
3. การคำนวณด้วย `+`, `-`, `*`, `//` และ `%`
4. เงื่อนไข `if`, `elif`, `else`
5. การทำงานซ้ำด้วย `while loop`
