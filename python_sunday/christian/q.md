# Python Project: Student Grading System

## Project Goal

Create a simple grading system using:

- `input()`
- Variables
- `if`
- `elif`
- `else`

The program will ask the user for their score and calculate their grade.

---

## Grading Rules

| Score | Grade |
|---|---|
| 80 - 100 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |
