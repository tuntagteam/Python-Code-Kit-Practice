Welcome to Google Docs Simulator

This is your practice area for typing and formatting. Try the tools above!

Features that work here

  • Type and edit text freely
  • Bold, Italic, Underline, Strikethrough
  • Change font and size
  • Text color and highlight color
  • Align text — left, center, right, justify
  • Bulleted and numbered lists
  • InsertTable, Link, Horizontal line, Special characters
  • Find and replace text (Ctrl+H)
  • Word count

Keyboard shortcuts to know

Ctrl+B = Bold  ·  Ctrl+I = Italic  ·  Ctrl+U = Underline  ·  Ctrl+Z = Undo  ·  Ctrl+H = Find
